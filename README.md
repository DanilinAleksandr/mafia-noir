# Мафия Online (mafia-noir)

Веб-игра «Мафия» для компании друзей: хост создаёт комнату, остальные заходят по ссылке с паролем, каждый видит свою роль на своём телефоне, игра идёт на сервере.

- **Боевой адрес:** https://mafia-noir.<поддомен-аккаунта>.workers.dev (см. «Деплой»)
- Память проекта и принятые решения — [CLAUDE.md](CLAUDE.md), план — [PLAN.md](PLAN.md).
- Пакеты: [движок](packages/engine/README.md), [протокол](packages/protocol/README.md), [сервер](packages/server/README.md), [клиент](packages/web/README.md).

## Локально

Нужен Node 22.12+.

```
npm install
npm run dev          # сервер :8787 (wrangler dev) + клиент :5173 (Vite)
npm test             # все тесты
npm run typecheck
npm run e2e          # полные партии через интерфейс (установленный Chrome)
```

Отладочная страница сервера (без оформления) — `http://127.0.0.1:8787/api/debug`, только в `wrangler dev`.

## Деплой

Один Cloudflare Worker `mafia-noir` на бесплатном плане: отдаёт собранный клиент (Workers Static Assets) и обслуживает `/api/*` и WebSocket по тому же адресу — один источник, без CORS. Комнаты — Durable Objects (SQLite), лимит создания комнат — Durable Object `Gate`.

Деплой — только через GitHub Actions (`.github/workflows/deploy.yml`): на каждый push в `main` — типы, сборка клиента, все тесты, проверка боевой сборки (`scripts/check-bundle.mjs`: нет отладочной страницы сервера и витрины сцен), затем `wrangler deploy`. Pull request'ы только проверяются.

Секреты репозитория: `CLOUDFLARE_API_TOKEN` (шаблон «Edit Cloudflare Workers») и `CLOUDFLARE_ACCOUNT_ID`. Без них проверка идёт, а деплой пропускается с предупреждением.

Задеплоить заново без изменений: Actions → «Проверка и деплой» → Run workflow (ветка `main`).

### Откат

Actions → «Откат» → Run workflow. Пустое поле — откат на предыдущую стабильную версию; можно указать ID версии из списка, который этот же workflow печатает (`wrangler versions list`). Откатывается и сервер, и клиент: статика входит в версию Worker. Данные комнат (Durable Objects) не откатываются; при смене формата комнаты (`ROOM_STATE_VERSION`) старые комнаты удаляются при загрузке.

### Пределы бесплатного плана

- Worker: 100 000 запросов в сутки, 10 мс процессорного времени на вызов. Файлы клиента запросами Worker не считаются.
- Durable Objects: 100 000 запросов и 100 000 записанных строк в сутки — примерно 280 партий на 10 игроков.
- Защита: не больше 6 новых комнат с адреса за 10 минут и 30 в сутки, всего — 120 в час и 600 в сутки; пароль — PBKDF2 10 000 итераций (~4 мс) и лимит попыток; WebSocket — только со своего Origin; сообщения — до 16 КБ, тело создания комнаты — до 2 КБ.
