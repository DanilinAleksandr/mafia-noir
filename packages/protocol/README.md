# @mafia/protocol

Общий протокол клиента и сервера «Мафии». Пакет без собственной логики игры: типы сообщений, проверка входящих, коды ошибок, настройки комнаты, коды комнат. Его используют и сервер (`@mafia/server`), и будущий веб-клиент (`@mafia/web`) — чтобы обе стороны понимали сообщения одинаково.

```
src/
  messages.ts   типы: ClientMessage, ServerMessage, RoomSnapshot, GameSnapshot, настройки, HTTP
  errors.ts     коды ошибок с русскими текстами, коды закрытия WebSocket
  settings.ts   настройки комнаты: значения по умолчанию, проверка и применение изменений, лимиты
  validate.ts   parseClientMessage — проверка всего, что пришло из сети; имена, чат
  codes.ts      коды комнат: алфавит без путаных символов, генерация, нормализация ввода
test/           модульные тесты (vitest)
```

Версия протокола — `PROTOCOL_VERSION`. Она передаётся в `hello`; при несовпадении сервер отвечает `PROTOCOL_VERSION` и закрывает соединение. Версию нужно поднимать при несовместимых изменениях сообщений.

Описание сообщений, стадий партии и ошибок — в [README сервера](../server/README.md), раздел «Протокол».

```
npm run test:protocol
```
