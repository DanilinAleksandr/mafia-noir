# @mafia/engine

Игровой движок «Мафии». Чистая логика на TypeScript: без зависимостей, без браузера, без Cloudflare.

- **Чистые функции.** Каждая функция получает состояние и возвращает новое; входное не меняется.
- **Состояние — обычный JSON.** `GameState` можно сохранить через `JSON.stringify`, загрузить и продолжить игру.
- **Детерминированность.** Вся случайность идёт от `seed`; состояние генератора лежит в `GameState.rng`. Тот же seed и те же действия дают ту же игру.
- **Сервер авторитетен.** Клиенту уходит только `viewFor(state, playerId)` — без чужих ролей, действий и результатов.

```
npm test            # из корня репозитория: все тесты движка
npm run typecheck   # проверка типов
```

## Быстрый пример

```ts
import {
  createGame, submitNightAction, allNightActionsIn, resolveNight,
  castVote, resolveVote, currentDecision, submitDecision, viewFor,
} from '@mafia/engine';

// Обычно роли раздаёт движок: createGame(config, [{ id, name }, …], seed).
// Здесь роли заданы явно, чтобы пример был однозначным.
const roles = ['mafia', 'doctor', 'commissioner', 'civilian', 'civilian', 'civilian'] as const;
const players = roles.map((role, i) => ({ id: `u${i}`, name: `Игрок ${i + 1}`, role }));
let { state } = createGame({ rules: { votingMode: 'secret' } }, players, 'seed-123');

// ночь: каждый игрок отправляет своё действие
state = submitNightAction(state, 'u0', { kind: 'mafiaVote', target: 'u3' }).state;
state = submitNightAction(state, 'u1', { kind: 'ability', ability: 'heal', targets: ['u3'] }).state;
if (allNightActionsIn(state)) { /* можно не ждать таймера */ }
let step = resolveNight(state);           // { state, events }
state = step.state;

// если кто-то должен принять решение (Охотник, Подрывник, Судья) — игра ждёт
const decision = currentDecision(state);   // { kind, playerId, options, condemned } | null

// день
state = castVote(state, 'u2', 'u0').state;
step = resolveVote(state);

// клиенту — только его представление
const view = viewFor(step.state, 'u2');
```

## API

Все функции, меняющие игру, возвращают `StepResult = { state, events }`: новое состояние и события этого шага. Недопустимый ввод — исключение `EngineError` с полем `code` (`WRONG_PHASE`, `DECISION_PENDING`, `NO_DECISION`, `UNKNOWN_PLAYER`, `PLAYER_DEAD`, `INVALID_ACTION`, `INVALID_TARGET`, `INVALID_CONFIG`, `INVALID_COMPOSITION`) и сообщением по-русски.

| Функция | Что делает |
|---|---|
| `createGame(config, players, seed)` | Собирает состав, раздаёт роли, открывает первую ночь. Порядок `players` — это места за столом. |
| `generateComposition(playerCount, config, seed)` | Состав по квотам: `{ ok: true, roles, counts, warnings }` или `{ ok: false, errors }`. |
| `validateComposition(roles, rules)` | Проверки готового состава: `{ errors, warnings, counts }`. |
| `nightOptions(state, playerId)` | Что игрок может сделать этой ночью: способности с допустимыми целями и голос мафии. |
| `submitNightAction(state, playerId, action)` | Принять ночное действие. До разрешения ночи его можно менять. |
| `allNightActionsIn(state)` | Все ли, кому есть что делать, ответили. |
| `nightMoveDone(state, playerId)`, `allNightMovesDone(state)` | Сделан ли ночной ход, включая «пустой» ход (`pass`) тех, кому делать нечего. Сервер ждёт всех живых, чтобы роль нельзя было вычислить по скорости ответа. |
| `pendingNightActors(state)` | От кого ещё ждут действия. **Только для сервера.** |
| `resolveNight(state)` | Разрешить ночь. Неответившие считаются отказавшимися. |
| `castVote(state, voterId, targetId \| null)` | Дневной голос; `null` — воздержаться. До подсчёта можно менять. |
| `allVotesIn(state)` | Все ли живые проголосовали. |
| `resolveVote(state)` | Подвести итог голосования. |
| `currentDecision(state)` | Решение, которого ждёт игра: `{ kind, playerId, options, condemned }` или `null`. |
| `submitDecision(state, playerId, decision)` | Принять решение игрока. |
| `resolvePendingDefault(state)` | Решение по умолчанию (для таймаута). |
| `checkWin(state)` | Итог игры (`GameResult`) или `null`, если игра продолжается. |
| `viewFor(state, playerId \| null)` | Представление игрока. `null` — общий экран. |
| `projectEvent(s)(state, event(s), playerId \| null)` | Проекция событий для зрителя (для рассылки событий шага). |

Ночные действия:

```ts
type NightAction =
  | { kind: 'ability'; ability: AbilityId; targets: PlayerId[] }  // применить способность
  | { kind: 'mafiaVote'; target: PlayerId | null }                // голос мафии (null — воздержаться)
  | { kind: 'pass' };                                             // отказаться от способности этой ночью
```

За ночь игрок применяет **одну** способность (у Ведьмы два зелья — одно за ночь). Чёрные дополнительно голосуют за жертву. Повторная отправка заменяет предыдущую.

Решения:

```ts
type Decision =
  | { kind: 'hunterShot'; target: PlayerId | null }  // null — не стрелять
  | { kind: 'bomberBlast'; target: PlayerId }
  | { kind: 'judgeVeto'; veto: boolean };
```

Каталог ролей — данные: `ROLES`, `ROLE_LIST`, а также `teamOf`, `categoryOf`, `winOf` (учитывают режим Любовницы).

## Ход игры и фазы

```
createGame → ночь 1 → день 1 → ночь 2 → день 2 → … → ended
```

`state.phase`: `night | day | ended`. `state.round` — номер круга (ночь N, затем день N).

**Отложенные решения.** Иногда игра не может идти дальше, пока игрок не решит: Охотник — в кого стрелять, Подрывник — кого забрать, Судья — отменять ли казнь. Тогда в `state.pending` появляется очередь решений, а `state.transition` помнит, куда перейти после неё. Пока очередь не пуста:

- ночные действия и голоса не принимаются (`DECISION_PENDING`);
- фаза не меняется (после ночи остаётся `night`, после голосования — `day`);
- победа **не проверяется** — предсмертный выстрел может изменить исход.

Когда очередь пустеет, движок проверяет победу и переходит к следующей фазе. Решения, которые стали невыполнимыми (некого выбирать), пропускаются сами.

## Роли

25 ролей. Способности и ограничения описаны данными в `src/roles.ts`.

### Красные, информационные

| Роль | Способность |
|---|---|
| **Комиссар** | Каждую ночь проверяет игрока: «мафия / не мафия». Дон — мафия, Маньяк — не мафия (настраивается). Прикрытый Адвокатом — «не мафия». |
| **Следователь** | Узнаёт точную роль игрока. Один раз за игру. |
| **Патрульный** | Следит за игроком и видит, кто к нему приходил этой ночью. |
| **Журналист** | Выбирает двух игроков и узнаёт, в одной ли они команде. Нейтральные — каждый сам за себя: два нейтрала всегда «разные». |
| **Бомж** | Ночует у игрока: видит его гостей и погибает вместе с ним, если хозяин погиб этой ночью (от чего угодно). Если хозяина спасли, Бомж жив. |

### Красные, защитные

| Роль | Способность |
|---|---|
| **Доктор** | Лечит игрока от всех нападений этой ночи. Нельзя лечить одного и того же две ночи подряд. Себя — можно (настраивается). |
| **Телохранитель** | Охраняет игрока (не себя). Все нападения на подопечного переходят на Телохранителя: он погибает, подопечный жив. Телохранителя может спасти Доктор. |
| **Священник** | Выбранного игрока нельзя казнить на следующий день. Нельзя выбирать одного и того же две ночи подряд. От ночных нападений не защищает. |
| **Герой** | Пассивно: переживает первое нападение (щит). От казни щит не спасает. |
| **Ведьма** | Зелье спасения (действует как лечение) и зелье убийства — каждое один раз за игру, за ночь только одно. Зелье спасения применяется вслепую и тратится, даже если на цель не напали. |

### Красные, активные

| Роль | Способность |
|---|---|
| **Охотник** | Погибая (ночью или на казни), может забрать одного игрока. Может не стрелять. |
| **Мэр** | Его голос на дневном голосовании считается за два. |
| **Судья** | Один раз за игру отменяет итог голосования: казни нет, наступает ночь. |
| **Купидон** | В первую ночь связывает двух игроков (может и себя): если погибает один, погибает и второй. |
| **Мирный житель** | Способностей нет. |

### Чёрные

Все чёрные знают друг друга и каждую ночь голосуют за жертву. Способность применяется вдобавок к голосу.

| Роль | Способность |
|---|---|
| **Мафия** | Только голос. |
| **Дон** | При равенстве голосов мафии побеждает цель, за которую голосовал Дон. |
| **Адвокат** | Прикрывает чёрного (можно себя): проверка Комиссара этой ночью покажет «не мафия». |
| **Шантажист** | Выбранный игрок молчит на следующем обсуждении (голосовать может). Нельзя выбирать одного и того же две ночи подряд. |
| **Консильери** | Каждую ночь узнаёт точную роль игрока. Результат видит вся чёрная команда. |

### Нейтральные

| Роль | Способность и цель |
|---|---|
| **Маньяк** | Убивает каждую ночь. Побеждает, оставшись один или вдвоём, когда мафии нет. |
| **Любовница** | Блокирует способность игрока на ночь. Нельзя блокировать одного и того же две ночи подряд. В нейтральном режиме побеждает, если жива в конце; в красном — играет за красных. |
| **Шут** | Побеждает, если его казнят днём. |
| **Выживший** | Побеждает, если жив в конце игры — с любой стороной. |
| **Подрывник** | Если его казнят, забирает одного из голосовавших против и побеждает. |

### Что значит «заблокирован»

Заблокированный Любовницей игрок этой ночью:

- не применяет способность (попытка **не тратится**: Следователь сохраняет проверку, Ведьма — зелье; запрет «два раза подряд» не срабатывает);
- если он чёрный — его голос за жертву не считается (единственный заблокированный мафиози никого не убивает);
- если он Охотник и погиб этой же ночью — не стреляет.

Заблокированный узнаёт, что его заблокировали, но не узнаёт кем. Пассивные способности (щит Героя, двойной голос, отмена Судьи) блокировка не трогает. Купидон разрешается раньше блокировок, поэтому заблокировать его нельзя.

### Что считается визитом

Любая ночная способность, направленная на другого игрока, — визит к нему (включая Купидона, Любовницу, Доктора, Комиссара). Исключение — наблюдение Патрульного: он смотрит со стороны. От мафии «приходит» один исполнитель — случайный из голосовавших за выбранную жертву. Гости перечисляются по порядку мест, без указания, зачем приходили.

## Порядок разрешения ночи

Все действия одной ночи **одновременны**: убитый этой ночью всё равно успевает применить способность (Доктор вылечит, Комиссар получит результат, Маньяк и мафиози могут убить друг друга).

1. **Купидон** (только первая ночь) — связывает пару.
2. **Блокировки** — Любовница. Несколько Любовниц действуют одновременно.
3. **Защиты** — Доктор, зелье спасения Ведьмы, Телохранитель, Священник.
4. **Атаки** — мафия, затем Маньяк, затем зелье убийства Ведьмы. Для каждой атаки:
   1. если цель охраняет Телохранитель, удар переходит на него;
   2. если получатель удара вылечен (Доктор или зелье) — спасён;
   3. иначе, если это Герой с целым щитом — щит потрачен, Герой жив;
   4. иначе — погибает.
5. **Эффекты** — Адвокат (прикрытие), Шантажист (молчание на завтра).
6. **Информационные роли** — Комиссар, Следователь, Консильери, Журналист, Патрульный, Бомж.
7. **Цепочки смертей** — погибшие от атак; Бомж вместе с хозяином; влюблённый вместе с парой; и так до тех пор, пока есть новые смерти. Затем — предсмертные выстрелы Охотников (отложенные решения).

**Голосование мафии.** Считаются голоса живых незаблокированных чёрных. Побеждает цель с наибольшим числом голосов. При равенстве: если Дон жив, не заблокирован и голосовал за одну из равных целей — она; иначе — случайная из равных (по seed). Никто не проголосовал — никто не убит. Голосовать за своих нельзя.

## День и голосование

- Голосование тайное и одновременное. Голос можно менять до подсчёта. Против себя голосовать нельзя. `null` — воздержаться; не проголосовавшие считаются воздержавшимися.
- Уходит кандидат с **наибольшей суммой голосов** (относительное большинство, даже если голос один). Голос Мэра — два.
- Никто не голосовал — никто не уходит.
- **Ничья** — одно переголосование: голосуют все живые, выбирать можно только из набравших поровну. Снова ничья — никто не уходит.

Когда приговорённый определён:

1. **Священник.** Если приговорённого защитили прошлой ночью — казни нет, все видят, что его спасло благословение (кто Священник — не видно). Судью не спрашивают.
2. **Судья.** Если жив Судья с неиспользованной отменой — игра ждёт его решения. Отменил — казни нет, наступает ночь; все видят, что итог отменён (кто Судья — не видно). Не отменил — отмена остаётся за ним. Несколько Судей решают по очереди, по местам.
3. **Казнь.** Приговорённый погибает; срабатывают цепочки (влюблённые, Охотник).
   - **Шут** и **Подрывник** получают личную победу; их роль объявляется всем.
   - **Подрывник** выбирает одного из живых игроков, голосовавших против него в решающем круге.

После дня наступает следующая ночь.

## Условия победы и граничные случаи

Победа проверяется после разрешения ночи и после завершения дня — когда приняты все отложенные решения.

| Сторона | Условие |
|---|---|
| **Красные** | Мертвы все чёрные и Маньяк. |
| **Чёрные** | Живых чёрных **не меньше**, чем остальных живых. Пока жив Маньяк — **строго больше**. |
| **Маньяк** | Чёрных нет, а в живых он один или вдвоём с кем-то. |
| **Шут, Подрывник** | Казнён днём (личная победа). |
| **Выживший, нейтральная Любовница** | Жив на момент конца игры. |

Победители в `GameResult.winners`: вся победившая команда (включая погибших), плюс личные победы, плюс живые «выживающие». Личные победы и «выжил» засчитываются при любом исходе, в том числе при ничьей.

### Граничные случаи и принятые решения

| Ситуация | Решение |
|---|---|
| Остались один мафиози и Маньяк | **Ничья** (`mafiaManiacStandoff`): ночью они убили бы друг друга. |
| Два мафиози и Маньяк, больше никого | Победа чёрных (2 > 1). |
| Мафии столько же, сколько остальных, но жив Маньяк (например, 2 мафиози, Маньяк и мирный) | Игра продолжается: Маньяк может сравнять счёт. |
| Все мертвы (мафиози и Маньяк убили друг друга) | **Ничья** (`everyoneDead`). |
| Угроз нет, а живы только нейтралы или вообще никто из красных | Победа красных — команда побеждает и посмертно. |
| Маньяк остался вдвоём с Выжившим | Побеждают оба. |
| Нейтралы при подсчёте паритета | Считаются среди «остальных» (не чёрных). |
| Маньяк втроём с двумя мирными, мафии нет | Игра продолжается. |
| Охотник убит ночью, без его выстрела был бы паритет | Сначала выстрел, потом проверка победы. |
| Казнён Шут | По умолчанию получает личную победу, игра продолжается. С правилом `jesterWinEndsGame` — игра сразу кончается исходом `jester`. |
| Шут или Подрывник убиты ночью либо застрелены Охотником | Не побеждают: нужна именно казнь. |
| Священник защитил Шута, Судья отменил казнь Подрывника | Казни не было — победы и взрыва нет. |
| На цель напали и мафия, и Маньяк, а Доктор её лечил | Спасена от обоих нападений. |
| На Героя напали дважды за ночь | Щит держит первое нападение, второе убивает. |
| Доктор лечил Героя | Щит не тратится. |
| Выстрел Охотника или взрыв Подрывника в Героя | Щит срабатывает. Лечение днём не действует. |
| Телохранитель охраняет, а на подопечного напали двое | Телохранитель погибает один раз, подопечный жив. |
| Влюблённый — Охотник, его пара погибла | Охотник гибнет от горя и стреляет. |
| Бомж ночует у влюблённого, чью пару убили | Гибнут все трое. |
| Цель Шантажиста погибла этой же ночью | Публичного объявления о молчании нет. |
| Блокировка лишила мафию всех голосов | Мафия никого не убивает. |
| Дон мёртв или заблокирован, голоса мафии поровну | Случайная цель из равных (по seed). |
| Никто из тех, кого Подрывник мог бы забрать, не жив | Взрыва нет, победа за казнь остаётся. |

## Состав игры

```ts
interface CompositionConfig {
  roles: { [role]: { enabled?: boolean; max?: number | null } };  // включение и лимит копий (null — без лимита)
  quotas: { [key]: { min?: number; max?: number; exact?: number } };
  preset: RoleId[] | null;                                        // точный список от хоста
  minCiviliansShare: number | null;                               // доля красных мест для Мирных; null — авто
}
```

Ключи квот: `black`, `neutral`, `redInfo`, `redDefense`, `redActive`, `redPlain` (Мирные жители) и общий `red` (все красные вместе). Любовница в красном режиме считается `redActive`, в нейтральном — `neutral`.

Пример из задания (6 игроков: 1 чёрный, 1 нейтральный, 4 красных, из них минимум 1 информационный и 1 защитный):

```ts
generateComposition(6, { composition: { quotas: {
  black: { exact: 1 }, neutral: { exact: 1 }, red: { exact: 4 },
  redInfo: { min: 1 }, redDefense: { min: 1 },
} } }, seed);
```

**Алгоритм.**

1. Собираются включённые роли и их лимиты копий (по умолчанию 1; у Мафии и Мирного жителя — без лимита). Роль, которой нужна выключенная роль (Адвокату — Комиссар), пропускается с предупреждением.
2. Вычисляются границы по категориям и проверяется выполнимость.
3. Минимумы закрываются случайными ролями своих категорий.
4. Остаток добирается случайными особыми ролями со свободным лимитом (в пределах максимумов квот) — но только пока Мирным жителям ещё хватает мест под их долю (см. ниже). Дальше — Мирные жители.
5. Роли с зависимостями: если в состав попал Адвокат, а Комиссара нет, Комиссар встаёт на место другой информационной роли; если информационных ролей в составе нет — Адвоката заменяет другая чёрная роль. Замены идут внутри одной категории, так что квоты не нарушаются.
6. Готовый состав проходит проверки баланса.

**Значения по умолчанию**, если квота не задана:

- чёрных — ровно `max(1, floor((N − 1) / 3))`: 4–6 игроков → 1, 7–9 → 2, 10–12 → 3, 13–15 → 4;
- нейтральных — от 0 до `floor(N / 5)`;
- красные категории — без ограничений.

**Доля Мирных жителей** (`minCiviliansShare`). Чтобы при многих включённых ролях состав не превращался в сплошные особые роли, Мирным отводится доля красных мест: их должно быть не меньше `round(доля × число красных)`.

- `null` (по умолчанию) — авто: `0.3` при 8 и более игроках, `0` при меньшем числе. Пример: 12 игроков, 3 чёрных, 1 нейтральный, 8 красных → минимум 2 Мирных.
- Число от 0 до 1 — действует при любом числе игроков; `0` отключает долю, `1` делает всех красных Мирными.
- Это ориентир, а не жёсткая квота: минимумы квот важнее. Если квоты или выключенный Мирный житель не дают набрать долю, состав всё равно собирается, а в `warnings` попадает `CIVILIAN_SHARE_UNMET`.
- Жёсткий минимум Мирных задаётся квотой `redPlain: { min: … }`.

**Проверки баланса** (ошибки): минимум 4 игрока; хотя бы один чёрный; чёрных меньше, чем остальных (максимум чёрных автоматически ограничивается этим условием). **Предупреждения**: роль бесполезна без другой (Адвокат без Комиссара); у красных нет информационных ролей при 6+ игроках.

**Ошибки** возвращаются списком с кодом, ключом квоты и сообщением по-русски, например:

- `QUOTA_UNSATISFIABLE` — «Красные информационные: по квоте нужно минимум 2, а включённые роли и их лимиты копий дают максимум 1»;
- `TOO_MANY_REQUIRED` — «Квоты требуют минимум 9 игроков (чёрные 2 + нейтральные 2 + красные 5), а игроков 6»;
- `NOT_ENOUGH_ROLES` — «Квоты и лимиты ролей позволяют раздать максимум 5 ролей (…), а игроков 8. Включите Мирного жителя, поднимите лимиты копий или ослабьте максимумы квот»;
- `RED_QUOTA_CONFLICT`, `QUOTA_INVALID`, `SHARE_INVALID`, `NO_BLACK`, `BLACK_NOT_MINORITY`, `TOO_FEW_PLAYERS`, `PRESET_INVALID`.

**Три способа раздать роли в `createGame`:** сгенерировать по квотам; задать `composition.preset` (список проверяется на баланс и перемешивается); задать `role` каждому игроку (ручная раздача и тесты — без проверок баланса).

## События

Событие — структурированная запись о том, что произошло. На событиях позже строятся анимации и сцены.

```ts
interface GameEvent {
  id: number;                    // порядковый номер в игре, с 1
  round: number;
  phase: 'setup' | 'night' | 'day' | 'ended';
  type: EventType;
  actors: PlayerId[];            // кто действовал
  targets: PlayerId[];           // на кого действовали
  data: { … };                   // зависит от type (см. EventDataMap в src/types.ts)
  visibility: Visibility;        // кто видит событие целиком
  stealth: StealthView | null;   // «скрытный» вид для остальных
}

interface Visibility { all: boolean; teams: Team[]; players: PlayerId[] }   // условия по «или»

interface StealthView {
  visibility: Visibility;   // кому показывать скрытный вид
  actors: boolean;          // показывать ли, кто действовал
  targets: boolean;         // показывать ли, на кого
  data: string[];           // какие ключи data можно показать
}
```

**Два уровня видимости.** `visibility` — кто видит событие целиком. `stealth` — что можно показать тем, кто целиком не видит, не раскрывая чужих ролей; если `stealth` равен `null`, остальные о событии не узнают вовсе. Примеры:

- *Убийство мафией.* Целиком (с исполнителем) видят чёрные; все остальные — скрытный вид: жертва и причина.
- *Блокировка.* Целиком видит Любовница; заблокированный — скрытный вид без `actors`: «меня заблокировали».
- *Спасение.* Целиком видит спаситель; все остальные (при `announceSaves`) — скрытный вид без участников: «кого-то спасли».
- *Проверка Комиссара.* Целиком видит Комиссар; скрытного вида нет.

Клиент получает `ViewEvent` — событие после проекции: те же поля без `visibility` и `stealth`, с флагом `redacted` (`true` — это скрытный вид, поля вырезаны). После конца игры (и мёртвым при `deadSeeAllRoles`) все события отдаются целиком.

### Типы событий

| Тип | actors → targets | data | Видят целиком | Скрытный вид |
|---|---|---|---|---|
| `gameStarted` | — | `playerCount` | все | — |
| `roleAssigned` | → игрок | `role` | сам игрок | — |
| `teamRevealed` | → чёрные | `roles` | чёрные | — |
| `nightStarted`, `dayStarted` | — | — | все | — |
| `loversLinked` | Купидон → пара | — | Купидон | пара: `targets` |
| `blocked` | Любовница → цель | — | Любовница | цель: `targets` |
| `blessed` | Священник → цель | — | Священник | — |
| `mafiaTargetChosen` | исполнитель → жертва | `votes`, `decidedBy` | чёрные | — |
| `saved` | спаситель → спасённый | `by`, `attack` | спаситель | все: ничего, только факт (при `announceSaves`) |
| `death` | убийца → погибший | `cause` | убийца / чёрные; для смертей без убийцы (казнь, горе, Бомж), выстрела Охотника и взрыва — все | все: `targets`, `cause` |
| `roleRevealed` | → игрок | `role` | все | — |
| `covered` | Адвокат → прикрытый | — | чёрные | — |
| `silenced` | Шантажист → цель | — | чёрные | все: `targets` |
| `checked` | Комиссар → цель | `isMafia` | Комиссар | — |
| `roleLearned` | Следователь / Консильери → цель | `role` | Следователь / чёрные | — |
| `visitorsSeen` | Патрульный / Бомж → хозяин | `visitors` | сам наблюдатель | — |
| `teamsCompared` | Журналист → двое | `sameTeam` | Журналист | — |
| `voteResult` | → лидеры | `stage`, `tally`, `abstained`, `outcome` | все | — |
| `ballotsRevealed` | — | `ballots` | все (в режиме `secret` — никто до конца игры) | — |
| `revoteStarted` | → кандидаты | — | все | — |
| `noExecution` | — | `reason` | все | — |

`by` у `saved`: `heal` (Доктор), `potion` (Ведьма), `guard` (Телохранитель), `armor` (щит Героя).

При `revealDeathCause: false` причина смерти убирается из скрытного вида, а события без убийцы целиком не видит никто (до конца игры).

## Представление игрока

`viewFor(state, playerId)` возвращает `PlayerView` — всё, что нужно клиенту, и ничего лишнего:

- `you` — своя роль, команда, счётчики способностей, влюблённые, молчит ли сегодня;
- `players` — список игроков; `role` и `team` заполнены только у тех, чью роль зритель вправе знать;
- `night` — свои варианты действий (`options`), что уже отправлено, готов ли; для чёрных — голоса команды;
- `day` — стадия, кандидаты переголосования, кто уже проголосовал, свой голос; все голоса — только в режиме `open`;
- `decision` — решение, которого ждут **от зрителя**; остальным — только `waitingForDecision: true`;
- `events` — журнал после проекции;
- `result` — итог игры.

**Чьи роли зритель знает:** свою; чёрные — всей чёрной команды; объявленные всем (после смерти при `revealRoleOnDeath`, после личной победы); узнанные им самим (Следователь) или его командой (Консильери); мёртвый при `deadSeeAllRoles` — все; после конца игры — все.

**Чего в представлении нет никогда:** чужих ролей и команд; чужих ночных действий (до и после разрешения); чужих результатов проверок; чужих голосов в режимах `secret` и `revealAfter` до подсчёта; того, от кого именно ждут решения; полей `visibility` и `stealth`; состояния генератора случайных чисел.

Результат проверки Комиссара — не раскрытие роли: в `players` роль проверенного остаётся `null`, результат лежит в событии `checked`.

## Что остаётся серверу

Движок не знает о времени, сети и комнатах. Серверу нужно:

- **Таймеры фаз.** По таймауту вызывать `resolveNight`, `resolveVote`, `resolvePendingDefault`. Досрочно — когда `allNightActionsIn` / `allVotesIn`.
- **Не выдавать роли паузами.** Ночь не должна заканчиваться раньше только потому, что у мирных нет действий: сервер ждёт «пустой» ход от всех живых (`allNightMovesDone`). То же с ожиданием Судьи: пауза после голосования выдаёт, что Судья есть, — можно делать её всегда.
- **Рассылка.** После каждого шага отправлять каждому игроку `viewFor(state, id)` и/или `projectEvents(state, step.events, id)`. Полное состояние и `pendingNightActors` клиентам не отправлять.
- **Обсуждение.** Движок только помечает молчащих (`day.silenced`); чат и микрофоны — забота сервера и клиента.
- **Отключившиеся игроки.** Движок их не различает: за них сработают таймауты.
- **Хранение.** `GameState` — обычный JSON.
