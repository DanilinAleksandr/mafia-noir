# @mafia/server (каркас, этап 2)

Пока пусто. Здесь будет авторитетный сервер игры:

- Cloudflare Worker + Durable Objects с WebSocket Hibernation (бесплатный план).
- Одна комната = один Durable Object; состояние игры (`GameState` из `@mafia/engine`) хранится в его storage как обычный JSON.
- Комнаты: код комнаты и пароль (хеш с солью), хост настраивает игру, переподключение по токену.
- Сервер вызывает функции движка и рассылает каждому игроку только его `viewFor(state, playerId)` и его проекции событий.

Что серверу нужно знать о движке, описано в [README движка](../engine/README.md), раздел «Что остаётся серверу».
