# @mafia/web (каркас, этап 3)

Пока пусто. Здесь будет клиент:

- Vite + React + TypeScript + Tailwind + Framer Motion, PWA.
- Клиент ничего не решает сам: он показывает `PlayerView`, полученный от сервера, и отправляет намерения игрока (ночное действие, голос, решение).
- Анимации и сцены строятся по событиям движка (`ViewEvent`): у события есть тип, участники и признак `redacted` (скрытный вид без чужих ролей).

Формат представления и событий описан в [README движка](../engine/README.md).
