# @mafia/web (каркас, этап 3)

Пока пусто. Здесь будет клиент:

- Vite + React + TypeScript + Tailwind + Framer Motion, PWA.
- Клиент ничего не решает сам: он показывает снимки, полученные от сервера, и отправляет намерения игрока (ночной ход, голос, решение, «готов»).
- Типы сообщений, коды ошибок и проверка настроек берутся из `@mafia/protocol`, типы представления и событий — из `@mafia/engine`.
- Анимации и сцены строятся по событиям (`ViewEvent`): у события есть тип, участники и признак `redacted` (скрытный вид без чужих ролей). В режиме «Кино» дополнительно приходят обезличенные сцены ночи.
- После ночи клиент проигрывает её итоги и отправляет `ready` — день начинается, когда готовы все.

Что почитать перед началом: [README сервера](../server/README.md) (протокол, стадии партии, режимы показа) и [README движка](../engine/README.md) (представление игрока, события).

Работающий пример клиента без оформления — отладочная страница сервера (`packages/server/src/debug-page.ts`).
