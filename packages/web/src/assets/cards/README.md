# Иллюстрации ролей

Положите сюда `<roleId>.webp` (например, `doctor.webp`, `mafia.webp`) — карточка роли подхватит
иллюстрацию при сборке. Пропорции 2:3, рекомендуемый размер 600×900. Если файла нет, карточка
рисует процедурную заглушку в цвете команды.

Список id ролей — `ROLE_IDS` в `packages/engine/src/types.ts`.
