# PLAN.md — «Мафия Online»

Живой план проекта. Обновляется в конце каждого этапа. Память проекта и принятые решения — в `CLAUDE.md`; подробности — в README пакетов.

## Этапы

| № | Этап | Статус |
|---|------|--------|
| 1 | `packages/engine`: игровой движок + тесты | **готов** |
| 2 | `packages/protocol` + `packages/server`: протокол, комнаты, Durable Object, тесты, боты | **готов** (без деплоя) |
| 2.1 | Правки сервера перед интерфейсом: «Кино», ведущий видит всё, вечерняя синхронизация | **готов** |
| 3 | `packages/web`: клиент (лобби, настройка состава, игровой экран), PWA | **готов** |
| 4 | Кинематографичный слой: сцены ночи и утра, круглый стол, анимации карточек | **идёт**: 4.1 и 4.2 готовы, следующий 4.3 |
| 5 | Иллюстрации ролей, звук, полировка | запланирован |
| — | Деплой на Cloudflare | отдельно, по команде |

## Архитектура

```
браузер (web) ──WebSocket──▶ Worker ──▶ Durable Object «Комната» ──▶ engine (чистые функции)
        ▲                                        │
        └──── room / game / chat (только своё) ◀─┘
```

- `@mafia/engine` — правила игры: состояние, ночь, день, победа, `viewFor`, события.
- `@mafia/protocol` — общий язык клиента и сервера: сообщения, проверка входящих, ошибки, настройки.
- `@mafia/server` — комнаты, вход, таймеры, рассылка; игровая логика только через движок.
- `@mafia/web` — показывает снимки и отправляет намерения игрока.

## Этап 1: движок (готов)

25 ролей, ночь и день, отложенные решения (Охотник, Подрывник, Судья), условия победы, генератор состава по квотам, `viewFor` без утечек, события с двухуровневой видимостью. 232 теста.

API (подробно — `packages/engine/README.md`):

```
createGame(config, players, seed)              → { state, events }
generateComposition(playerCount, config, seed) → { ok, roles, counts, warnings } | { ok: false, errors }
nightOptions / submitNightAction / allNightActionsIn / nightMoveDone / allNightMovesDone / resolveNight
castVote / allVotesIn / resolveVote
currentDecision / submitDecision / resolvePendingDefault
checkWin(state)                                → GameResult | null
viewFor(state, playerId | null, { seeAll? })   → PlayerView
projectEvents(state, events, playerId | null, { seeAll? }) → ViewEvent[]
```

Формат события: `id`, `round`, `phase`, `type`, `actors`, `targets`, `data`, `visibility` (кто видит целиком), `stealth` (скрытный вид для остальных: кому, показывать ли участников, какие поля данных).

## Этап 2: сервер (готов)

Сделано:

- **Правка движка:** доля Мирных жителей (`minCiviliansShare`, по умолчанию 30% красных мест при 8+ игроках); «пустой» ночной ход (`nightMoveDone`, `allNightMovesDone`); Адвокат не остаётся без Комиссара.
- **Протокол** (`@mafia/protocol`): версия, типы сообщений, проверка входящих, коды ошибок с русскими текстами, настройки комнаты, коды комнат.
- **Комнаты:** код из 5 символов без путаных, ссылка `/r/КОД`, пароль хешем PBKDF2, лимит неверных попыток, токен переподключения, лобби с онлайн-статусом, исключение и передача прав, автопередача хоста через 2 минуты, режимы «хост играет» и «ведущий-наблюдатель», запрет входа после старта, удаление через 6 часов простоя.
- **Настройки:** роли, квоты, правила движка, таймеры (по умолчанию выключены), режим показа: «Скрытный», «Открытый состав», «Кино».
- **Партия:** ночь с «пустыми» ходами (конец — когда сходили все, по таймеру или по кнопке хоста); отложенные решения только нужному игроку; утренняя синхронизация (`ready`, 15 с, кнопка хоста); день; чат мафии для живых чёрных.
- **Проверка без интерфейса:** интеграционные тесты внутри workerd; сетевой тест на утечки с перехватом всех сообщений каждого клиента; `npm run bots`; отладочная HTML-страница.
- **Локальная работа:** `wrangler dev` без входа в Cloudflare.

Описание протокола, стадий и ограничений — `packages/server/README.md`.

### Этап 2.1: правки перед интерфейсом (готов)

- **«Кино»** — не общие сцены, а личные: игрок узнаёт роль того, кто ночью подействовал на него (`scenes: { id, round, ability, role, saved }`). «Открытый состав» без изменений, «Кино» его включает.
- **Убийца не раскрывается никогда**, ни в одном режиме: в событии `death` автора видит только он сам (у мафии — команда) и ведущий.
- **Ведущий-наблюдатель видит всё:** роли, журнал целиком, чужие ходы и голоса в реальном времени (`view.backstage`), чат мафии. Тест на утечки различает ведущего и игроков.
- **Вечерняя синхронизация:** после дня — стадия `evening`; ночь начинается, когда готовы все, через 15 секунд или по решению хоста.
- В движок добавлены событие `abilityUsed` и параметр `seeAll` у `viewFor`.

Итог: 351 тест (232 + 16 + 103), `npm test` зелёный, `npm run typecheck` чистый. Мутационная проверка: 13 утечек, все пойманы.

## Этап 3: веб-клиент (готов)

Сделано (подробно — `packages/web/README.md`):

- **Пакет `@mafia/web`:** Vite 8 + React 19 + TypeScript + Tailwind 4 + Framer Motion, PWA (манифест, иконки, service worker), шрифты в сборке, тексты в `i18n/ru.ts`.
- **Связь:** WebSocket с `hello` по токену или имени и паролю, запросы с `ack`/`error` по номеру, `ping`, переподключение с задержкой и по возвращении на вкладку, окончательное закрытие по кодам 4000–4003, проверка живости комнаты по HTTP. Адрес сервера — `VITE_SERVER_URL`, в разработке Vite проксирует `/api` на wrangler.
- **Экраны:** главная, создание, вход по коду и по ссылке `/r/КОД`, лобби (онлайн-статус, «Поделиться», исключение и передача прав, причины «нельзя начать»), настройки хоста (наборы ролей и свои наборы в localStorage, роли с описаниями и лимитами, квоты, доля Мирных, ручной состав, правила, таймеры, режимы показа и хоста), справочник ролей, раздача роли с удержанием карточки, ночь (одинаковый ход у всех, чат мафии, прогресс без имён), отложенные решения, утро с личной карточкой, обсуждение, голосование и переголосование, вечер, режим зрителя, экран ведущего («закулисье», журнал, чат), финал и «Сыграть ещё раз».
- **EventPresenter** (`src/presenter/`): события → такты → очередь представлений → рендереры. Единственная точка, через которую идут визуальные реакции; этап 4 заменит рендереры.
- **Карточка роли** 2:3: иллюстрация `src/assets/cards/<roleId>.webp` или процедурная заглушка в цвете команды.
- **Сервер:** стадия `discussion` перед голосованием и таймер `timers.discussion` (протокол v2, формат комнаты v3); бот-хост открывает голосование; отладочная страница знает новую стадию.
- **Проверка:** 30 компонентных тестов; e2e Playwright на установленном Chrome — партия пятью «телефонами» с переподключением и новой партией, партия ведущего с игроком и ботами `npm run bots`; сценарий скриншотов 24 экранов в `docs/screens/` (просмотрены, исправлены утечки роли «через плечо», обрезка мини-карт, грамматика рода).

Итог: 382 теста (232 + 16 + 104 + 30), `npm test` и `npm run typecheck` зелёные, e2e зелёные.

## Этап 4: кинематографичный слой (идёт)

Подэтапы; после каждого — коммит, скриншоты в `docs/scene-shots/` и ожидание «дальше».

### 4.1 Колода и карточки (готов)

- **Правка 0:** «Блокнот» в шапке у всех (у чёрных — чат и голоса команды, у остальных — личные заметки); подписей голосов команды на основной панели нет; о новом сообщении — вибрация.
- **Инфраструктура:** сцена — изолированный ленивый компонент (`scenes/types.ts`, `registry.ts`); часы сцен на главном таймлайне GSAP (пропуск, скорость, пауза, кадр, перемотка); `SceneStage` (тап — пропуск, «Пропустить у всех» у хоста); частицы canvas 2D как функция времени; звуки — синтез Web Audio + Howler; вибрация; настройки «Звук», «Вибрация», «Уменьшить анимацию», «Мягкие эффекты»; авто-снижение качества на слабых устройствах и при просадке кадров.
- **Витрина** `/dev/scenes` и `npm run scene-shots` (17 кадров «Колоды»: 4 роли × 4 момента + упрощённый режим).
- **Карточки:** арт `assets/cards/<roleId>.webp` и `back.webp`, рамка и табличка кодом, процедурная заглушка (гильош, лучи, медальон), голограмма (палец, гироскоп, блик, плёнка, параллакс).
- **Сцена «Колода»:** колода → дуга с вращением → переворот со вспышкой и искрами → название по буквам → карточка-голограмма; напарники мафии; «Спрятать».
- Начальный бандл: +2 КБ gzip; «Колода» с GSAP и Howler — ленивый кусок 46 КБ gzip.

### 4.2 Ночь и утро (готов)

- «Пробуждение»: веки открываются (маска-щель с размытием).
- Личная сцена (что случилось с тобой), затем общая утренняя.
- Убийца не показывается никогда: выстрел из-за кадра, нож, КАМАЗ без водителя, рояль/кирпич, яд, взрыв — вид смерти случаен и не зависит от убийцы.
- Режимы: «Скрытный» — только предметы и эффекты (пластырь, крестики, шприц; щит; помада/сердце); «Открытый состав» — силуэты и карточки подействовавших ролей; «Кино» — полные карточки по сценам сервера. Бомж и убитый вместе падают только в общей сцене.
- «Мягкие эффекты»: чернила, дым, ткань вместо крови.
- Информационные результаты: досье со штампом, газета Журналиста, следы Патрульного.
- Общая сцена: рассвет, карточки погибших падают на стол, переворот с ролью; спокойное утро, если погибших нет.
- Тест: в «Скрытном» режиме ни одна сцена не получает и не рисует идентификатор чужой роли.

Сделано: сцена `scenes/morning/` по плану выше; личные сцены во всех режимах (сервер, протокол v3); синхронизация 25 с; витрина — 19 случаев утра. Правки перед 4.2: одинаковая ночная панель у всех ролей (тест на 25 ролей), название на карточке сверху рукописным шрифтом, нестабильный тест ботов (ошибка теста; точная сверка числа сцен, 200 прогонов зелёные). Скриншоты: `docs/scene-shots/morning-*.png`.

### 4.3 Круглый стол и голосование (следующий)

- Стол сверху с лёгкой перспективой (CSS 3D), места игроков, карточки рубашкой вверх с именами, своя — внизу.
- Вращение пальцем с инерцией, переключение на список; выбор кандидата, «Проголосовать» — фишка/печать с вибрацией; до раскрытия — только «проголосовали N из M».
- Раскрытие: фишки летят к карточкам, счётчики нарастают, лидер выдвигается; казнь — печать «ПРИГОВОР», молоток, переворот с ролью; вставки Мэра, Судьи, Священника, Шута, Подрывника, Охотника.
- Обсуждение — за тем же столом.

### 4.4 Финал и полировка

Сцены побед команд и раскрытие всех карточек по кругу стола.
