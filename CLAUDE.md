# CLAUDE.md — память проекта «Мафия Online»

Каждый этап ведётся в новом чате без истории. **Перед любой работой прочитай этот файл и `PLAN.md`. В конце этапа обнови оба.**

## Что это

Веб-игра «Мафия» для компании друзей. Один создаёт комнату, остальные заходят по ссылке с паролем, каждый видит свою роль на своём телефоне, игра идёт на сервере. Только бесплатные зависимости и бесплатные сервисы.

Общение с пользователем, документация, комментарии в коде и сообщения об ошибках — по-русски. Идентификаторы в коде — по-английски.

## Архитектура

Monorepo на npm workspaces (`packages/*`), Windows, Node LTS.

| Пакет | Что | Статус |
|---|---|---|
| `packages/engine` (`@mafia/engine`) | Чистая игровая логика на TypeScript. Без зависимостей, без браузера, без Cloudflare. | **готов (этап 1)** |
| `packages/server` (`@mafia/server`) | Cloudflare Worker + Durable Objects с WebSocket Hibernation, бесплатный план. | каркас (README) |
| `packages/web` (`@mafia/web`) | Vite + React + TypeScript + Tailwind + Framer Motion, PWA. | каркас (README) |

Принципы:

- **Сервер авторитетен.** Вся логика на сервере. Клиент получает только `viewFor(state, playerId)` и никогда чужие роли, кроме разрешённых случаев (мафия знает своих; мёртвые видят всех, если включено; в финале открыто всё).
- **Движок — чистые функции.** Вход не меняется, возвращается `{ state, events }`. `GameState` — обычный JSON. Вся случайность — от seed (`state.rng`).
- **Анимации строятся на событиях.** У события есть тип, участники, видимость и «скрытный» вид (что можно показать, не раскрывая чужих ролей).

## Команды


## Как устроен движок (коротко)

- Фазы: `night → day → night → … → ended`. `round` — номер круга.
- Каждая меняющая функция: `begin(state)` (глубокая копия) → правки черновика и `emit(...)` → `finish(ctx)`.
- **Отложенные решения** (`state.pending`): Охотник (в кого стрелять), Подрывник (кого забрать), Судья (отменять ли казнь). Пока очередь не пуста, действия не принимаются, фаза не меняется, победа не проверяется. `state.transition` помнит, куда идти дальше. Продвигает игру `advance()` в `flow.ts`.
- Роли описаны данными; логика способностей — в `night.ts` по `ability.id` и `ability.step`.
- Идентификаторы команд: `red` / `black` / `neutral`. Причины смерти: `mafiaKill`, `maniacKill`, … — намеренно **не совпадают** с id ролей: тест на утечки ищет в представлении строки вида `"doctor"`. Не вводи значений, совпадающих с id ролей.

## Принятые решения по правилам

Спорные места, решённые на этапе 1 (подробно — в README движка, раздел «Граничные случаи»):

- **Победа чёрных:** чёрных ≥ остальных живых; пока жив Маньяк — строго больше. Один мафиози против Маньяка — **ничья**. Все мертвы — ничья.
- **Победа красных:** мертвы все чёрные и Маньяк; команда побеждает и посмертно.
- **Маньяк:** мафии нет, он один или вдвоём с кем-то.
- **Шут:** личная победа при казни; игра по умолчанию **продолжается** (правило `jesterWinEndsGame` — заканчивать сразу).
- **Подрывник:** условие победы — быть казнённым (как у Шута) плюс взрыв. Убит ночью или застрелен — не побеждает.
- **Выживший и нейтральная Любовница:** побеждают, если живы в конце, с любой стороной.
- **Купидон:** влюблённые только умирают вместе; условия победы у них не меняются (отдельной «команды влюблённых» нет).
- **Ночь одновременна:** убитый этой ночью успевает применить способность.
- **Защита:** сначала Телохранитель перехватывает удар, потом лечение, потом щит Героя. Доктор спасает от всех нападений за ночь.
- **Щит Героя** работает против любых нападений, включая выстрел Охотника и взрыв Подрывника; не работает против казни, горя влюблённого и гибели Бомжа с хозяином.
- **Блокировка Любовницы:** способность не срабатывает и не тратится; голос мафии не считается; заблокированный Охотник, убитый той же ночью, не стреляет. Купидона заблокировать нельзя.
- **«Не два раза подряд»** действует у Доктора (по заданию), а также у Священника, Шантажиста и Любовницы (добавлено для баланса).
- **Все чёрные роли голосуют** за жертву вдобавок к своей способности. Исполнитель — случайный из голосовавших за жертву.
- **Ведьма:** одно зелье за ночь; зелье спасения применяется вслепую и тратится в любом случае.
- **Консильери** узнаёт роль каждую ночь, результат видит вся чёрная команда. **Следователь** — один раз за игру.
- **Журналист:** нейтралы — каждый сам за себя, два нейтрала всегда «разные команды».
- **Голосование:** относительное большинство; против себя нельзя; ничья → одно переголосование среди равных → снова ничья → никто не уходит.
- **Священник** срабатывает раньше Судьи; Судью спрашивают после объявления итога.
- **Причина смерти публична** по умолчанию (`revealDeathCause`), спасения объявляются анонимно (`announceSaves`).
- **Состав:** по умолчанию чёрных `max(1, floor((N−1)/3))`, нейтральных до `floor(N/5)`; остаток — сначала особые роли, потом Мирные жители.

## Сделано

- **Этап 1 (движок):** все 25 ролей, ночь, день, отложенные решения, условия победы, генератор состава с квотами и понятными ошибками, `viewFor` без утечек, события с двухуровневой видимостью, 210 тестов (включая случайные игры на утечки, детерминированность и неизменяемость).

## Запланировано

1. **Этап 2 — сервер** (`packages/server`): Worker + Durable Object комнаты, WebSocket Hibernation; код комнаты и пароль (хеш с солью), хост настраивает игру, переподключение по токену; таймеры фаз через alarms; рассылка `viewFor` и проекций событий.
2. **Этап 3 — веб-клиент** (`packages/web`): лобби, настройка состава и правил, игровой экран, PWA.
3. **Этап 4 — кинематографичный слой:** сцены ночи и утра, круглый стол, анимации карточек — по событиям движка.
4. **Этап 5 — иллюстрации ролей**, звук, полировка.

## Открытые вопросы

- **Подрывник:** оставить победу «за казнь» или сделать его «выживающим» со взрывом как сдерживанием?
- **Шут:** значение `jesterWinEndsGame` по умолчанию (сейчас игра продолжается).
- **Состав по умолчанию:** при всех включённых ролях Мирных жителей почти не остаётся — возможно, нужны готовые наборы («классика», «хаос») на стороне клиента.
- **Дон:** классической проверки «ищет Комиссара» нет (в задании не было) — добавлять ли?
- **Первая ночь:** убийства идут с первой ночи; нужна ли «ночь знакомства» без убийств?
- **Влюблённые из разных команд:** нужна ли им общая победа?
- **Бомж:** нападение на него дома срабатывает, даже если он ночует у другого игрока — оставить так?

## Известные ограничения

- Движок не знает о времени: таймауты, обсуждение и отключения игроков — забота сервера.
- Ожидание решения Судьи после голосования выдаёт паузой, что Судья есть. Серверу стоит делать паузу всегда (см. README движка, «Что остаётся серверу»). То же с длительностью ночи.
- Нет защиты от «вечной» партии, если никто не действует (например, Маньяк не убивает, а днём никого не казнят) — серверу нужен лимит кругов или таймауты.
- Мирные жители не обязаны ничего отправлять ночью; чтобы не выдавать роли скоростью ответа, сервер должен собирать «подтверждение» у всех.
